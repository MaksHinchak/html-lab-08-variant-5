# Лабораторна №8. Пояснення для захисту

## Що вимагалося

Намалювати на canvas фігури свого варіанта з №6 та запрограмувати подію, яка трансформує і переміщує частину фігур. Мій варіант 5 містить два кола, шість прямокутників і ромб. Умова міститься на першій сторінці Lab8_WP_HTML_JS_2026.pdf. Нижче на ній помилково написано №7, але назва документа й тема стосуються №8.

## Що відкрити й показати

1. Відкрити `canvas.html` у браузері через кнопку Chrome в PyCharm або пункт Canvas у меню сайту.
2. Показати 9 синіх фігур і порівняти зі сторінкою SVG.
3. Залишити вибраним ромб. Ввести X = 0.5, Y = 0.5, кут = 45, масштаб = 0.75. Натиснути «Застосувати».
4. Центр ромба переміщується з (3; -1) у (3.5; -0.5), фігура повертається і зменшується.
5. Вибрати коло, застосувати інші параметри. Ромб зберігає свої зміни.
6. Натиснути «Відновити всі фігури».
7. У коді показати тег canvas у HTML і команди getContext, arc, rect, translate, rotate, scale у JavaScript.

## Теги й команди просто

`canvas` - прямокутне полотно. `width` та `height` визначають розмір його піксельного буфера. CSS визначає, якого розміру воно виглядає на сторінці. Текст усередині canvas описує малюнок для середовищ, які його не підтримують.

`getContext("2d")` дає інструмент двовимірного малювання.

| Команда | Значення |
| --- | --- |
| beginPath | Почати новий контур. |
| arc | Побудувати дугу, а з повним кутом 2π - коло. |
| rect | Побудувати прямокутник. |
| moveTo | Перейти до точки без малювання лінії. |
| lineTo | Додати відрізок до наступної точки. |
| closePath | Замкнути фігуру. |
| fill / stroke | Зафарбувати / обвести контур. |
| fillStyle / strokeStyle | Колір заливки / обводки. |
| translate | Перемістити початок координат. |
| rotate | Повернути систему координат на кут у радіанах. |
| scale | Змінити масштаб. |
| save / restore | Зберегти / відновити стан контексту. |
| setTransform | Задати базове перетворення для нового кадру. |
| fillText | Намалювати підпис. |

Новим основним HTML-тегом є canvas. Form, select, option, input, button використовуються для керування й уже траплялися у попередніх роботах. Методичка не вимагає використати весь довідник Canvas-команд.

## Як отримано координати

`translate(290, 245)` ставить математичний нуль у точку полотна. `scale(72, -72)` означає 72 одиниці полотна на одиницю координат і спрямовує додатну вісь Y вгору. Підписи малюються після restore, щоб текст залишався у звичайному напрямку.

Кола мають центри (-2; 1) і (1; 1), радіус 1. Ромб має вершини (2; -1), (3; 0), (4; -1), (3; -2). Для прямокутників збережено ті самі області, що й у №6.

## Як працює подія

Форма має обробник submit. `preventDefault()` утримує поточну сторінку, `reportValidity()` перевіряє допустимі числа. Значення записуються в окремий стан вибраної фігури, потім викликається draw.

Draw заново зафарбовує фон і малює всі фігури. Для кожної викликається save, перенесення до її центра зі зсувом, поворот, масштаб, побудова контуру, restore. Тому перетворення однієї фігури не переходить на наступну.

Градуси переводяться в радіани формулою `angle * Math.PI / 180`. Кут 45° дорівнює π/4. Масштаб 0.75 означає 75% початкового розміру.

Форма дозволяє кілька подій з різними параметрами, але безперервної анімації для цього завдання не потрібно. Повторне малювання також виконується після зміни розміру вікна. Буфер враховує devicePixelRatio, щоб лінії були чіткі на Retina.
